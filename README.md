## 🚀 Featured Projects

### 🏢 AI Building Footprint Detection

AI-based building footprint extraction from high-resolution satellite imagery.

**Focus:** Computer Vision · Semantic/Instance Segmentation · GeoAI · GIS

**Tools:** Python · PyTorch · Mask R-CNN · Rasterio · GeoPandas · QGIS

🔗 [View Repository](https://github.com/zh4rif/AI_Model_Building_Footprint)

---

### 🛰️ PyGMTSAR / InSAR

Work with satellite interferometry and remote sensing workflows for analysing surface deformation using SAR imagery.

**Focus:** InSAR · Sentinel-1 · SAR · Remote Sensing · Geospatial Analysis

🔗 [View Repository](https://github.com/zh4rif/pygmtsar)

---

### 🛰️ Pico-Satellite Prototype

Prototype for integrated data acquisition and environmental analytics in pico-satellite systems.

The project combines sensor integration, data acquisition, onboard processing concepts, communication and environmental analytics.

**Focus:** Embedded Systems · Sensors · Satellite Systems · Environmental Data

🔗 [View Repository](https://github.com/zh4rif/Pico-Setellite-Prototype)

---

### 🗺️ Malaysia Traffic / Geospatial Visualization

Web-based geospatial visualization project using HTML and JavaScript for working with Malaysian geospatial data.

**Focus:** Web GIS · Geospatial Visualization · JavaScript
